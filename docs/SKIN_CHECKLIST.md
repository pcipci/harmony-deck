# Skin checklist

Every skin mock (and every real skin) must show the same elements, so skins stay comparable:

1. Activity tiles: free, running, part of the running activity, selected, "going" (just started)
2. Device tiles and the room tabs (selected / other)
3. Direct keys: free, pressed/active state (a key that has a state, for example Play), app keys
4. State keys and the mute key (pressed / not pressed look must stay the same family in every skin)
5. Volume slider (including +/- keys and the value)
6. Settings switch (off / on) and the segment switch (Activities / Devices)
7. Power knob (device view) with the lamp
8. Hold to switch off: progress and the final effect
9. Markings: network symbol, lock, hint badge on the gear
10. A window (gear, lifebuoy, profile) and the info table
11. Reduced motion: the skin must work without any animation
